Common fixes

ShotPDF says it can't capture this page

Chrome blocks every extension from capturing its own pages, such as chrome:// settings, the New Tab page, other extensions and the Chrome Web Store. Open a regular website and try again. For PDF files opened in Chrome, download the PDF instead.

Nothing happens when I press a shortcut

Another extension or app may be using the same keys. Open chrome://extensions/shortcuts, find ShotPDF and set keys that are free. The shortcuts ShotPDF is using right now are listed in its Settings page.

A full page capture has gaps or repeated parts

Some sites load content while you scroll or use their own scrolling area. Scroll to the bottom of the page once, go back to the top, then capture again. If a sticky banner repeats, turn on “Keep sticky headers only at the top” in Settings.

Only part of a web app was captured

Apps such as email clients or chat tools scroll inside a panel rather than the whole page. ShotPDF captures what the page itself scrolls. Use Visible area or Select area for those panels.

A very long page looks slightly smaller

Browsers limit how big a single image can be. When a page is extremely tall, ShotPDF scales it down a little instead of failing, so the whole page still fits.

Copy image doesn't work

Very large images can be too big for the clipboard. Download the file instead, or crop the capture first. Also make sure the ShotPDF tab is in front when you click Copy.

The PDF breaks through an image or table

Choose PDF, then set PDF pages to One page. The whole capture is saved on a single long page with no breaks.

Where are my files?

In your Chrome Downloads folder. Press Ctrl+J (Cmd+Shift+J on Mac) to open the downloads list.

How do I capture a dropdown or hover menu?

In the ShotPDF popup, set Delay to 3s or 5s, click Full page or Visible area, then open the menu. A countdown shows on the ShotPDF icon before it captures.
